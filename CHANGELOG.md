# Журнал изменений

В этом файле фиксируются все значимые модификации проекта «PRR9 Auth».

## [1.0.0] — 18.11.2026

### ✨ Реализовано
- Модуль авторизации на базе Clean Architecture и паттерна MVI (UDF).
- Интерфейс на Jetpack Compose с индивидуальной пастельно-розовой темой Material 3.
- Увеличенная компоновка экрана входа (карточка занимает 75% высоты дисплея).
- Управление состоянием через `StateFlow` и `ViewModel`.
- Мгновенная валидация полей (email и длина пароля) с использованием вычисляемых свойств UiState.
- Компонент `SnackbarHost` для отображения сетевых ошибок.
- Внедрение зависимостей через Dagger Hilt (UseCase → ViewModel, Repository → UseCase).
- Экран профиля (`HomeScreen`) с отображением данных пользователя и функцией выхода.

### 🐛 Устранено
- Несоответствие версий JVM: явно задан `jvmTarget = 17` для предотвращения конфликтов между KSP и JavaCompiler.
- Удалён устаревший атрибут `package` из `AndroidManifest.xml` (управление перенесено в `namespace` файла `build.gradle.kts`).
- Увеличен объём памяти Gradle Daemon до 2 ГБ (`-Xmx2048m`) для исключения сбоев при компиляции Compose и KSP (ошибка JVM garbage collector thrashing).
- Удалён шаблонный `ExampleInstrumentedTest.kt`, вызывавший ошибки линковки из-за отсутствия зависимостей androidTest.

### ⚙️ Модернизировано
- Обновлены версии плагинов: Kotlin 2.0.21, Hilt 2.51.1, KSP 1.0.28, Compose BOM 2024.09.00.
- Осуществлён переход с `kapt` на `ksp` для ускорения генерации кода Hilt.
